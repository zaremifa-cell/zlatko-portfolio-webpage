# Mandatory design system

Before beginning any design, UI, UX, layout, visual frontend, or responsive-design task in this workspace, read [`Geometric and Perceptual System for Text-Based Interfaces.md`](./Geometric%20and%20Perceptual%20System%20for%20Text-Based%20Interfaces.md) in full and use it as the mandatory design system.

Apply its requirements for perceptual grouping, hierarchy, the 4-point spacing scale, text measure, contrast, touch targets, responsive modes, optical correction, and accessibility. User directions may add to or explicitly override individual visual decisions, but do not replace the system by default.
